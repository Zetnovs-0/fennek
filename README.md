# ФЕНЁК

Воксельная интерактивная история о подростке, строгой семье и одном вечере, который меняет всё.

Ты — семнадцатилетний(яя) подросток. Родители больше заняты младшим братом и приёмной сестрой, а твоя мечта об университете кажется им несерьёзной. После ссоры с мамой ты выходишь во двор и у мусорных баков встречаешь фенька. Забрать его домой или оставить — первый выбор из многих.

Игра полностью работает в браузере, без сборки и без внешних запросов: Three.js и шрифты лежат локально.

## Запуск

Нужен любой статический сервер (ES-модули не открываются через `file://`).

```bash
cd fennek-story
python3 -m http.server 8080
# открыть http://localhost:8080
```

Или:

```bash
npm start
# или
./start.sh 8080
```

Подойдёт и любой другой сервер, например `npx serve .`.

## Управление

- **WASD / стрелки** — ходить
- **пробел / клик по реплике** — продолжать диалог
- **1, 2, 3** — выбирать варианты
- **E** — осмотреть предмет рядом (воспоминания дают маленькие бонусы)
- **Esc** — пауза
- **мышь** — вращать камеру, колесо — приблизить
- **клик по полу** — идти в точку
- на телефоне: тап по полу, свайп по сцене, кнопка **✦** для осмотра

Прогресс сохраняется автоматически после каждого выбора. Концовки открываются в галерее и остаются между прохождениями. Игра рассчитана примерно на 20–30 минут одного прохождения.

## Что внутри

- **8 концовок** и десятки развилок; судьба фенька, отношения с семьёй и поступление зависят от выборов.
- Две большие ветки: забрать фенька или оставить его у баков. Внутри — выбор имени, три вечера перед экзаменом, разговор с мамой и финальное решение.
- Воксельные сцены: комната, кухня, двор, класс, гостиная, титульный экран и мастерская персонажа.
- Создание персонажа: имя, местоимения в тексте, внешность и мечта (архитектура / код / медицина).
- Маленькие интерактивные воспоминания: стол, плакат, семейный альбом, записка на холодильнике и другие.
- Процедурный эмбиент и звуки на WebAudio; кнопка звука есть на титуле и в паузе.
- Адаптивная вёрстка для телефона, сохранение в `localStorage`.

## Структура

```
index.html              экраны и разметка интерфейса
css/style.css           оформление, адаптив
js/main.js              игровой цикл, сцены, UI, сохранения
js/story.js             вся история, выборы, проверка концовок
js/worlds.js            воксельные локации
js/voxel.js             мини-движок вокселей и общие материалы
js/characters.js        персонажи и фенёк
js/audio.js             процедурный звук
vendor/three.module.js  Three.js r160 (MIT)
assets/fonts/           Pixelify Sans и Manrope (SIL OFL)
tools/check-story.mjs   обход графа истории и проверка всех концовок
```

## Проверка истории

```bash
npm run check
```

Скрипт обходит все состояния, проверяет ссылки между узлами и печатает пример пути к каждой концовке.

## Сохранения

- `fennek_save_v1` — текущее прохождение;
- `fennek_endings_v1` — открытые концовки;
- `fennek_muted` — настройка звука.

Очистить прогресс можно в меню браузера (данные сайта) или через консоль:

```js
localStorage.removeItem('fennek_save_v1');
localStorage.removeItem('fennek_endings_v1');
```
